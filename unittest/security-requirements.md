# Security Requirements - json_search()

## Security Requirements

- SR-01: Chỉ role admin được phép đọc apiKey.
- SR-02: Chỉ role admin và operator được phép đọc managementIpAddress.
- SR-03: Admin, operator và viewer được phép đọc issueSummary.

Các security requirements trên sẽ được sử dụng để xây dựng
security test ở bước tiếp theo.
